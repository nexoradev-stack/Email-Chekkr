    How it works

    From a messy list to one you can send to, in three steps.

    1. Add your emails

      Type one address, or upload a CSV of up to 10,000 rows. Truvio finds the email column for you.

    2. Truvio checks each one

      Format, domain, mail server, temporary inboxes, team addresses and typos. Each address gets a result and a score.

    3. Download a clean list

      Get your file back with the results added, or download only the valid addresses.

      What each result means

      Every address gets one of four results and a score from 0 to 100.

      • Valid

        Well-formed, and the domain has a working mail server. No warning signs. Safe to send.

      • Risky

        The domain takes email, but something is off: a temporary inbox, a team address like info@, a likely typo, or no mail server record.

      • Invalid

        Badly formed, or the domain doesn't exist or doesn't accept email. Sending will bounce.

      • Unknown

        The domain didn't answer in time. Check it again later before removing it.

      What Truvio checks

      • The address is written correctly
      • The domain exists
      • The domain has a mail server that accepts email
      • The domain isn't a temporary inbox (10,000+ known services)
      • The address isn't a team inbox like info@ or sales@
      • Common typos, like gmial.com or company.con

      What it doesn't do

      • It doesn't log in to mail servers, so "valid" means the address and domain look deliverable, not that this exact mailbox was confirmed.
      • It never sends an email to anyone on your list.
      • It doesn't store your addresses. Only the part after the @ is looked up.

      Questions

      Is my list uploaded anywhere?

      No. Your CSV is read and checked inside your browser. To see if a domain receives email, Truvio asks a public DNS service about the domain only (for example example.com), never the full address.

      Why is an address "risky" and not "valid"?

      Its domain takes email, but there's a warning sign: a temporary inbox, a team address, a likely typo, or no mail server record. You decide whether to keep it.

      How many addresses can I check?

      Up to 10,000 rows per file. Bigger lists can be split into several files.
