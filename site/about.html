About Truvio

Truvio helps you clean an email list before you send to it. Fewer bounces protect your sender reputation, so more of your emails reach real inboxes.

How it checks an address

  1. Reads the address and checks it's written correctly.
  2. Looks up the domain to see that it exists and has a mail server.
  3. Compares the domain with a list of over 10,000 temporary inbox services.
  4. Flags team addresses like info@ and support@, and suggests fixes for common typos.
  5. Gives the address a result (valid, risky, invalid or unknown) and a score from 0 to 100.

What makes it different

Your list never leaves your computer. Checks run in your browser, and only the domain part of each address (like acmecorp.com) is looked up through a public DNS service.

Who builds it

Truvio is an independent project, built with help from Claude (by Anthropic) and Cursor. The code is on GitHub.
